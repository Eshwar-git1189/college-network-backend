AskOnce – Student Interaction Platform

Problem
Students rely on scattered sources for academic updates and mentorship.

Solution
Centralized MERN web application with role-based communication and event management.

Tech Stack
React | Node.js | Express | MongoDB | JWT | Google OAuth

Features Implemented
- Authentication & authorization
- User roles (student / faculty / club)
- Posts & mentorship requests
- Event management APIs

Planned Features
- Real-time messaging (Socket.IO)
- Recommendation system
- Notifications
